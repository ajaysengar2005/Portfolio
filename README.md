## Overview

A modern, responsive portfolio website built with HTML5, CSS3, and JavaScript. This portfolio showcases my skills, projects, and experience as a Full Stack Developer, featuring interactive elements and voice commands for enhanced user experience.

## 🌟 Features

### Interactive UI/UX
- ✨ Custom animations with hover effects
- 🎯 Smooth scrolling navigation
- 🌓 Dark/Light theme toggle with local storage
- 🌌 Dynamic Particle.js background effects
- 📱 Fully responsive design for all devices

### Voice Commands
- 🎤 Voice navigation through website sections
- 🗣️ Voice-controlled project viewing
- 🔊 Welcome message with voice feedback
- 🎧 Cross-browser voice recognition support

### Skills Showcase
- 💡 Interactive skill cards with animations
- 📊 Dynamic progress bars
- 🔍 Category-based filtering system
- 🎭 Smooth animated transitions

### Contact Form
- 📧 EmailJS integration for direct messaging
- ✅ Real-time form validation
- 📬 Success/Error handling with feedback
- 🔄 Dynamic form state management

## 🛠️ Technologies

### Frontend
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (ES6+)
- Particles.js
- Font Awesome Icons
- Google Fonts

### Backend Integration
- EmailJS for contact form
- Web Speech API for voice commands
- Local Storage for theme persistence

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Git (for cloning)
- Local development server (optional)

### Installation

1. Clone the repository
```bash
https://github.com/ajaysengar2005/Portfolio
```

2. Navigate to project directory
```bash
cd portfolio
```

3. Open `index.html` in your browser or use a local server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

## 💻 Usage

1. **Navigation**
   - Use the navigation menu or scroll through sections
   - Click the theme toggle for dark/light mode
   - Use voice commands for hands-free navigation

2. **Skills Section**
   - Filter skills by category
   - Hover over skill cards for animations
   - View skill progress bars

3. **Contact Form**
   - Fill in your details
   - Get real-time validation feedback
   - Receive confirmation on successful submission
